# Automatic-Image-Colorization
Steps to run the notebook:

1. Upload the notebook to Google Colab
2. Before you run the notebook, make sure to load the dataset onto Colab. For this, on the left-hand sidebar of the Colab window, click on Files (has a file icon) and then on "upload to session storage" to upload the dataset I've attached in the repo directly into the Colab runtime. Beware though, you will need to reupload the files after the runtime disconnects since it is temporary storage.
3. Run all the cells in the notebook. There are a total of 8 parts in the notebook: Setup, Configuration, Loading the dataset, segmentation and feature extraction, SVR, MRF Smoothing with ICM, Evaluation on Test Set and an option to colorize your own images.

The repository contains the required source code and the dataset, alongwith the presentation and a two-page summary of our project.
